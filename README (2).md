## 01. Il progetto

**Heartagram Italia** nasce come archivio digitale indipendente dedicato alla documentazione, valorizzazione e divulgazione della storia musicale e dell'identità artistica di Ville Valo e degli HIM.

Il progetto esplora le relazioni tra musica, immaginario gotico, simbolismo, cultura visiva e sensibilità romantica.

L'obiettivo è costruire un punto di riferimento editoriale italiano, accessibile e progressivamente aggiornabile, che riunisca contenuti storici, biografici, discografici e culturali.

## 06. Architettura e tecnologie

Il progetto è predisposto per la distribuzione statica attraverso **GitHub Pages**.

Tecnologie dell'edizione statica:

- HTML5 semantico
- CSS3 responsive
- Layout adattabile a desktop, tablet e smartphone
- Navigazione accessibile
- Git e GitHub per il versionamento
- GitHub Actions per la distribuzione automatizzata

L'edizione statica attualmente predisposta rappresenta un adattamento della homepage originale. Non costituisce ancora un'esportazione completa di tutte le pagine, fotografie e funzionalità presenti su ChatGPT Sites.
